# بازی مین‌روب (Minesweeper)

یک پیاده‌سازی مدرن و تحت وب از بازی کلاسیک و خاطره‌انگیز مین‌روب که با استفاده از HTML، CSS و جاوا اسکریپت خالص ساخته شده است.

## ویژگی‌ها

- **۳ سطح دشواری**: آسان (۹×۹)، متوسط (۱۶×۱۶) و سخت (۳۰×۱۶).
- **امنیت در کلیک اول**: کلیک اول شما در بازی هرگز روی مین نخواهد بود.
- **تغییر پوسته (تم)**: قابلیت سوییچ بین حالت تاریک (Dark Mode) و روشن (Light Mode).
- **دو زبانه**: پشتیبانی کامل از زبان‌های فارسی (راست‌چین) و انگلیسی (چپ‌چین).
- **طراحی ریسپانسیو**: قابل اجرا و بازی روی گوشی‌های موبایل و دسکتاپ.
- **ذخیره تنظیمات**: انتخاب‌های شما برای تم و زبان در حافظه مرورگر (Local Storage) ذخیره می‌شود و با رفرش صفحه از بین نمی‌رود.

## آموزش بازی

۱. **کلیک چپ (یا لمس)** روی یک خانه، آن را باز می‌کند.
۲. **کلیک راست (یا لمس طولانی)** روی یک خانه، پرچمی را در آنجا قرار می‌دهد تا نشان‌دهنده وجود مین باشد.
۳. اعدادی که روی خانه‌های باز شده می‌بینید، نشان می‌دهند که در ۸ خانه اطراف آن، دقیقاً چند مین وجود دارد.
۴. با استفاده از منطق و اعداد، مکان تمام مین‌ها را پیدا کنید.
۵. شما زمانی برنده می‌شوید که تمام خانه‌هایی که مین ندارند را باز کنید.
۶. اگر روی یک خانه دارای مین کلیک کنید، بازی را می‌بازید!

## نحوه دانلود و اجرا

برای اجرای این بازی به هیچ نصب، سرور یا ابزار بیلد کردنی نیاز ندارید!

۱. این مخزن (Repository) را دانلود یا کلون کنید:
   ```bash
   git clone https://github.com/yourusername/minesweeper.git
   ```
۲. به پوشه دانلود شده بروید.
۳. فقط کافیست فایل `index.html` را با مرورگر دلخواه خود (کروم، فایرفاکس، سافاری و ...) باز کنید.
۴. از بازی لذت ببرید!

## تکنولوژی‌های استفاده شده

- HTML5
- CSS3 (تکنیک‌های Flexbox, Grid و متغیرهای CSS)
- جاوا اسکریپت خالص (Vanilla JS)
- فونت‌آوسام (FontAwesome) برای آیکون‌ها
- فونت زیبای وزیرمتن (Vazirmatn) برای متون فارسی
